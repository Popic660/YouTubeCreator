# YouTube Dark Style

Визуальный стандарт приложения. Интерфейс повторяет тёмную тему YouTube и YouTube Studio: те же цвета, шрифт, радиусы, ссылки и состояния.

Значения сняты с тёмной темы youtube.com (вычисленные стили, ноябрь 2026) и со скриншотов YouTube Studio. Светлой темы нет. Хром видеоплеера не переносить на каркас приложения.

Перед вёрсткой читать этот файл целиком. Не подменять токены «похожими» цветами из других систем.

## Каркас

```
+------+--------------------------------------------------+
|      | masthead 56                                     |
|      | [=]  logo     ( search pill 40 )      icons     |
+------+--------------------------------------------------+
|      |                                                  |
| 240  |  content on #0f0f0f                              |
| guide|  surfaces step up by fill, not by shadow         |
|      |                                                  |
+------+--------------------------------------------------+
        menus and dialogs float on #282828
```

Страница плоская. Карточка отделяется более светлой заливкой или обводкой. Тень есть только у меню, диалога и другой всплывающей панели.

Подложка модального окна: `rgba(0, 0, 0, 0.6)`.

Порядок слоёв снизу вверх: контент, липкая шапка, меню, подложка, диалог.

## Кнопки

Основной размер приложения — M.

| Размер | Высота | Радиус | Текст | Поля | Иконка | Иконка-кнопка |
|---|---|---|---|---|---|---|
| XS | 24px | 12px | 12px | 0 8px | 16px | 24×24 |
| S | 32px | 16px | 12px | 0 12px | 16px | 32×32 |
| M | 40px | 20px | 14px / 500 | 0 16px | 24px | 40×40 |
| L | 48px | 24px | 18px | 0 24px | 24px | 48×48 |
| XL | 56px | 28px | 24px | 0 32px | 24px | 56×56 |

У контурной кнопки горизонтальное поле на 1px меньше: обводка 1px съедает его. У фокуса поле меньше ещё на 2px, внешний размер не меняется.

Варианты:

| Вариант | Фон | Текст | Обводка |
|---|---|---|---|
| Залитая | fill | text-inverse | нет |
| Залитая, наведение | fill-hover | text-inverse | нет |
| Тональная | tonal | text | нет |
| Тональная, наведение | tonal-hover | text | нет |
| Контурная | прозрачный | link | 1px outline |
| Текстовая | прозрачный | text или link | нет |
| Неактивная | не менять заливку | text-disabled | нет |

Сегмент вроде лайка и дизлайка — одна капсула из двух тональных кнопок. Левая: радиус `20px 0 0 20px`. Правая: `0 20px 20px 0`. Между ними разделитель 1px.

Фокус с клавиатуры: сплошная обводка 2px. Мышиный ховер обводку фокуса не заменяет.

## Карточка ролика

Превью 16:9, радиус 12px.

Длительность стоит внизу справа с отступом 8px на крупном превью и 4px на мелком. Фон `badge`, текст `badge-text`, 12px / 500, радиус 4px, поле `1px 4px`, высота 20px.

Бейдж New: фон `badge-special`, текст `badge-special-text`, та же геометрия.

Прямой эфир: фон `live`, текст белый.

Прогресс просмотра по нижнему краю превью: высота 4px, дорожка `progress-track`, просмотренная часть — градиент от `progress` к `progress-end`.

Под превью: заголовок 14px / 500 / 20px, цвет `text`, не больше двух строк. Канал, просмотры и дата — 12px / 400 / 18px, цвет `text-secondary`.

В результатах поиска заголовок крупнее: 18px / 400 / 26px. Короткий фрагмент описания там 12px и цвет `text`, не secondary.

## Аналитика, таблица, требования

Поле графика: фон `plot`. Линия серии может быть своим цветом данных. Оси и подписи — `text-secondary`.

Выбранный период — выбранный чип. Остальные периоды — обычные чипы.

Таблица: фон строки прозрачный на `canvas`. Наведение строки — `menu` или `selected`. Заголовок колонки 12px, `text-secondary`. Действие строки, например «Скачать», появляется на наведении и берёт тональную или контурную кнопку.

Полоса требования: дорожка `outline` или `plot`, заполнение `link`, высота несколько пикселей. Текст прогресса — `text-secondary`. Это не красный прогресс превью.

Раскрывающаяся секция: строка на всю ширину, шеврон справа, разделитель `divider`.

Информационная плашка: фон чуть светлее холста, иконка цвета `link`, действие — контурная кнопка.

## Иконки

Глиф 24px в зоне 40px, если размер кнопки не задаёт иное. Цвет иконки совпадает с цветом текста этого контрола. Неактивная иконка — `text-disabled`.

Иконки линейные, со скруглёнными окончаниями, как в шапке и сайдбаре YouTube. Не подменять их другим набором с другой толщиной штриха внутри одного экрана.

## Движение

Появление меню и диалога около 200ms. Закрытие около 50ms. Смена цвета при наведении короткая, без пружины и без увеличения кнопки.

## Запрещено

- Светлая тема и фон `#000000` или `#1e1e1e`.
- Шрифт Segoe UI, Inter, системный UI как основной.
- Синий ссылки браузера `#0000ee` и фиолетовый Material.
- Радиус 4px у кнопок и радиус-капсула у полей ввода.
- Тень под карточкой ленты, строкой таблицы и сайдбаром.
- Копия знака YouTube. Акцент `#ff0033` — цвет марки приложения, не логотип YouTube.
- Хром плеера (`#eeeeee` на полупрозрачном чёрном) для обычных кнопок приложения.
