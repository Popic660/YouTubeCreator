# Техническое задание: YouTube Shorts Creator

Статус: рабочее ТЗ продукта. Это документ для разработки, не реализация.

Визуальный закон: `docs/youtube-dark-style.md`. Если этот файл и гайд расходятся во внешнем виде, верен гайд.

Код проекта — C++20. Этапы ниже идут по порядку. Этап N не включает функции этапа N+1.

Канал в приложении — уже существующий канал пользователя, подключённый через вход Google. Приложение само аккаунты Google не создаёт и пароли не хранит.

## 1. Назначение

Локальное приложение для Windows. Человек ведёт библиотеку шортсов по папкам, каждой папке задаёт стилевой промпт, собирает ролик вручную на таймлайне и может отдать тему конвейеру: текст, озвучка, клипы, постер. Готовый ролик уходит на один или несколько своих каналов. По уже опубликованным роликам и по каналам в том же окне видна статистика YouTube.

Своего сервера у программы нет. Библиотека, проекты, ключи моделей и токены каналов лежат на машине пользователя.

## 2. Внешний вид

Тёмная тема. Холст `#0f0f0f`. Шрифт `Roboto, Arial, sans-serif`. Текст `#f1f1f1`, вторичный `#aaaaaa`, ссылка `#3ea6ff`. Залитая кнопка: фон `#f1f1f1`, текст `#0f0f0f`. Серая кнопка и ховер пункта: `rgba(255, 255, 255, 0.1)`.

Кнопка — капсула. Основной размер 40px, радиус 20px, текст 14px / 500. Чип 32px, радиус 8px. Превью и плашка — радиус 12px. Поле ввода — радиус 4px. Карточки без тени. Тень только у меню и диалогов, фон меню `#282828`.

Светлой темы нет. Знак YouTube не копируется. Акцент приложения — `#ff0033` из гайда. Хром плеера YouTube на кнопки приложения не переносится.

Остальные токены, сетка, меню, формы и аналитика — в `docs/youtube-dark-style.md`. Перед любой вёрсткой читать гайд целиком.

## 3. Главное окно

Пока шортс не выбран, центр пустой. Инструменты по бокам кадра выключены. Таймлайн в пустом состоянии.

```
+------------------------------------------------------------------------+
| шапка 56: знак, поиск по именам папок и роликов, меню каналов          |
+------+-------------------------------------------+------+--------------+
|      |                                           |      | поиск        |
| инст-|           кадр 9:16                       | опера| дерево папок |
| румен|           пусто или превью                | ции  | превью       |
| ты   |                                           |      | шортсов      |
+------+-------------------------------------------+------+              |
| таймлайн: видео, звук, волны, ползунок            |                     |
+---------------------------------------------------+---------------------+
```

Шапка высотой 56px. Поиск в шапке фильтрует дерево по имени папки и имени ролика. Пустой результат поиска показывает вторичный текст «Ничего не найдено».

Слева от кадра — инструменты узкой колонкой: выбор, лезвие, рука, текст, масштаб. Справа от кадра — операции над текущим роликом: разрез по ползунку, кадрирование, масштаб и положение, громкость, удаление. Дальше справа — дерево папок на всю высоту рабочей области.

Режимы центра:

- Шортс не выбран: пустой холст, инструменты выключены, таймлайн пуст.
- Выбран шортс: кадр 9:16 и таймлайн.
- Выбрана статистика канала или уже выложенного ролика: аналитика по гайду (поле графика `#3f3f3f`, периоды чипами), таймлайн скрыт. Дерево остаётся на месте.

Меню папки (фон `#282828`): создать, переименовать, удалить, изменить промпт.

## 4. Библиотека

### 4.1. Папки

Папка имеет имя, родителя и промпт стиля. Папки вкладываются друг в друга. Дерево раскрывается. Внутри папки видны превью шортсов.

Операции: создать, переименовать, удалить, задать промпт, перетащить ролик в другую папку.

Промпт папки — свободный текст: стилистика, голос, что должно быть в ролике, запреты. Вложенная папка получает промпт родителя и добавляет свой. Поиск по тексту промпта в эти этапы не входит: только имена папок и роликов.

Удаление папки, в которой есть ролики, спрашивает подтверждение. Проекты на диске удаляются только после подтверждения.

### 4.2. Шортс

У ролика есть имя, папка, сценарий, таймлайн, постер и статус.

Статусы: черновик, генерация, готов, выложен.

Пока нет кадра, карточка в дереве — заглушка. После появления кадра или постера карточка показывает превью. Заголовок карточки — не больше двух строк. Длительность — бейдж на превью по гайду.

## 5. Данные на диске

Пользователь выбирает папку библиотеки.

```
библиотека/
  library.db
  media/<asset>/исходник
  shorts/<id>/project.json
  shorts/<id>/poster
  exports/
  cache/waveforms/
```

`library.db` — SQLite: папки, ролики, каналы, публикации, задачи, индекс имён для поиска.

`project.json` — таймлайн ролика.

Секреты моделей и токены Google — в защищённом хранилище Windows (DPAPI), не открытым текстом в sqlite и не в json проекта.

Сущности:

```
Папка
  имя, родитель, промпт стиля
  дочерние папки и шортсы

Шортс
  имя, папка, сценарий, таймлайн, постер, статус

Дорожка таймлайна
  видео V1
  видео V2 (текст и картинка поверх)
  звук: голос, музыка, эффекты
  клип: файл, вход, выход, масштаб, позиция, громкость

Канал
  channel id, название, токен обновления в защищённом хранилище

Публикация
  шортс, канал, id видео на YouTube, приватность, время выгрузки

Задача
  шаг конвейера, прогресс, ошибка, повтор
```

Проект автосохраняется. Незавершённая задача после перезапуска помечается прерванной и её можно повторить.

## 6. Монтаж

Редактор собирает один вертикальный ролик. Это монтажный стол шортса: дорожки, резка, кадр, звук, экспорт.

В кадре и на таймлайне:

- воспроизведение и перемотка по ползунку;
- видеодорожка V1 и дорожка наложения V2 для текста и картинки;
- несколько звуковых дорожек;
- добавление своего аудио;
- отдельная обрезка звука и видео;
- форма волны;
- лезвие, подрезка краёв, громкость клипа;
- масштаб и положение кадра, вписывание материала в 9:16;
- текст на экране;
- отмена и повтор;
- автосохранение проекта.

Экспорт — файл 1080×1920, H.264 + AAC, через FFmpeg. Сборка идёт из таймлайна. Сгенерированный и вручную собранный ролик выходят одной дорогой.

За этими этапами остаются цвет как в Lumetri, мультикамера, вложенные секвенции, ключевые кадры анимации, маски и переходная библиотека Premiere. Их можно добавить отдельным этапом после того, как стол уже режет и экспортирует.

## 7. Конвейер ИИ

Пользователь вводит тему. Папка уже хранит стиль. Шаги передают результат друг другу. Каждый шаг можно выключить, сменить модель и поправить шаблон промпта. Ключи моделей хранит пользователь.

```
тема + промпт папки
        |
        v
   [текст] сценарий и сцены
        |
        +--> [голос] клип на дорожку голоса
        |
        +--> [видео] клип на сцену, на видеодорожку
        |
        +--> [постер] кадр для карточки в дереве
        |
        v
   таймлайн, который можно править руками
        |
        v
   экспорт --> публикация
```

Инструмент — один вызов модели с входом, выходом, отменой, прогрессом и ошибкой. Конвейер — заданный порядок инструментов. На этапах 7 и 8 конвейер такой: текст, голос, клипы, постер. Свободный агент, который сам выбирает инструменты, начинается после этапа 11 и в этапы 1–11 не входит.

Контракт инструмента общий для всех поставщиков. В каркас закладывается OpenAI-совместимый HTTP, чтобы локальные и облачные чат-модели подключались без нового кода на каждый адрес. Первого живого поставщика каждого вида выбирают в начале соответствующего этапа.

Первый набор, когда дойдут этапы 7 и 8:

| Шаг | Вход | Выход | Первый кандидат |
|---|---|---|---|
| Текст | тема, промпт папки | сценарий и список сцен | OpenAI-совместимый чат |
| Голос | сценарий, голос из промпта | аудиоклип на дорожке голоса | ElevenLabs или TTS того же чат-провайдера |
| Видео | сцена, стиль папки | видеоклип на V1 | один видео-API с адаптером (Kling, Veo или аналог); выбор в начале этапа 8 |
| Постер | название, стиль, сценарий | картинка карточки в дереве | image API того же семейства |

Ролик можно собрать без генерации видео: свой файл, голос из конвейера, ручная подрезка. Генерация кладёт клипы на таймлайн и не отдаёт готовый mp4 мимо редактора.

Музыку на этих этапах пользователь кладёт файлом сам.

Задача конвейера видна на ролике: прогресс, отмена, повтор. Ошибка шага не затирает уже готовые клипы и сценарий.

Постер карточки в дереве — вертикальный кадр ролика. Отдельная картинка 1280×720 для обложки YouTube ставится при публикации, если канал разрешает свою обложку. Если канал не разрешает, публикация проходит без своей обложки и это показано в статусе.

## 8. YouTube

### 8.1. Подключение канала

Вход — OAuth Google в браузере, ответ на локальный порт. Токен обновления лежит в защищённом хранилище Windows. После входа ссылка и название канала только подписывают запись. Ссылка вместо входа не подключает канал: выгрузка и статистика по одной ссылке не открываются.

Разрешения: загрузка видео, чтение канала и списка роликов, чтение аналитики.

Каналов может быть несколько. Канал можно отключить. Отключение удаляет локальный токен и не удаляет ролики на YouTube.

### 8.2. Публикация

Одна залитая кнопка «Опубликовать». В диалоге уже подставлены название и описание из сценария. Пользователь отмечает каналы и выбирает приватность: личный, по ссылке или открытый.

Перед отправкой ролик экспортирован, кадр вертикальный, длительность не длиннее текущего предела Shorts. Предел сверяется с документацией YouTube в начале этапа 10. До этой сверки ориентир — 180 секунд.

Ошибка на одном канале не отменяет загрузку на остальные. У каждой публикации свой статус и id видео.

Квота проекта Google по умолчанию — 10 000 единиц в сутки. Одна вставка видео стоит около 1 600 единиц. Это около шести выгрузок в сутки на проект, пока квоту не поднимут. Остаток квоты виден до нажатия «Опубликовать». Цифру квоты на этапе 10 сверяют с актуальной документацией Google.

### 8.3. Статистика

Статистика запрашивается явно и хранится локально вместе со временем синхронизации.

- По ролику из Data API: просмотры, лайки, комментарии.
- По каналу: подписчики и суммарные просмотры.
- По Analytics API за выбранный период: просмотры, время просмотра, средняя длительность, лайки.
- Показы и CTR пишутся, только если канал их отдаёт. Иначе в ячейке текст «нет в этом канале».

У графика аналитики подпись: данные YouTube, задержка может быть до двух суток. Счётчики Data API новее, чем график аналитики.

Экран аналитики следует разделу гайда «Аналитика, таблица, требования»: поле графика `plot`, периоды чипами, таблица без тени карточки.

## 9. Стек

Рабочее решение этого ТЗ:

- C++20 и CMake;
- Qt 6 и Qt Quick для окна: токены гайда становятся темой, таймлайн — свой элемент сцены;
- FFmpeg для декодирования, волн и экспорта;
- SQLite для библиотеки;
- сеть Qt для моделей и YouTube API;
- первый релиз — Windows 10 и новее.

Qt выбран из-за таймлайна и видео. Гайд остаётся источником цветов, шрифта и радиусов.

## 10. Этапы

Каждый этап заканчивается программой, которую можно открыть. Следующий этап не переделывает работу предыдущего.

```
1 каркас --> 2 библиотека --> 3 просмотр --> 4 таймлайн --> 5 кадр --> 6 экспорт
                                                                      |
                                                                      v
                                                            7 текст и голос
                                                                      |
                                                                      v
                                                            8 клипы и постер

2 библиотека --> 9 каналы --> 10 публикация --> 11 статистика
                      ^              ^
                      |              |
                   OAuth          нужен экспорт (этап 6)
```

Этапы 9–11 можно вести после этапа 2 параллельно с монтажом только в той части, которая не требует таймлайна. Публикация (этап 10) начинается после экспорта (этап 6) и каналов (этап 9). Статистика (этап 11) начинается после каналов и хотя бы одной публикации.

### Этап 1. Каркас

Окно по схеме раздела 3. Тема из гайда. Пустой центр. Выключенные инструменты. Пустое дерево. Сборка CMake на Windows.

Готово, когда окно открывается и пустое состояние совпадает с гайдом: холст, шрифт, шапка 56px, радиусы кнопок и полей.

### Этап 2. Библиотека

Папки: создать, переименовать, удалить, вложить, задать промпт. Поиск по имени. Перетаскивание ролика между папками. В дереве карточка-заглушка, пока нет кадра. Промпт вложенной папки наследует родителя.

Готово, когда после перезапуска дерево, имена и промпты на месте.

### Этап 3. Просмотр

Импорт видео в папку. Выбор ролика включает кадр 9:16, воспроизведение и перемотку. Без выбора центр снова пустой.

Готово, когда импортированный файл смотрится из дерева и пустое состояние возвращается, если выбор снят.

### Этап 4. Таймлайн

Дорожки видео и звука, волна, лезвие, подрезка, громкость, добавление аудиофайла, отмена, автосохранение.

Готово, когда обрезка звука не обязана совпадать с обрезкой видео и проект после перезапуска открывается с теми же краями клипов.

### Этап 5. Инструменты кадра

Кнопки слева и справа от кадра выполняют действия: масштаб, положение, кадрирование в 9:16, текст.

Готово, когда горизонтальный исходник занимает вертикальный кадр предсказуемо и правится этими кнопками.

### Этап 6. Экспорт

Сборка таймлайна в mp4 1080×1920, H.264 + AAC.

Готово, когда экспорт открывается как обычное вертикальное видео и совпадает с тем, что видно в кадре: те же склейки, громкость и кадрирование.

### Этап 7. Текст и голос

Настройки ключей. Тема ролика. Промпт папки. Сценарий. Голос отдельным клипом на звуковой дорожке. Шаг видео выключен.

Готово, когда из одной темы в папке со стилем получается сценарий и дорожка голоса, которую можно подрезать руками на таймлайне этапа 4.

### Этап 8. Клипы и постер

Сцены сценария становятся клипами на V1. Постер появляется на карточке в дереве. У задачи есть прогресс, отмена и повтор.

Готово, когда после генерации таймлайн редактируется и экспорт этапа 6 собирает эти клипы.

### Этап 9. Каналы

Несколько каналов через OAuth. Список в меню шапки. Отключение канала. Токены в защищённом хранилище.

Готово, когда два канала видны после перезапуска, а паролей Google в базе и в файлах проекта нет.

### Этап 10. Публикация

Кнопка «Опубликовать». Выбор каналов. Приватность. Прогресс по каждому каналу. Запись id видео. Проверка вертикали и длительности до отправки. Сообщение о квоте.

Готово, когда один экспорт уходит на выбранные каналы и у каждого виден свой статус. Сбой одного канала оставляет остальные загрузки как есть.

### Этап 11. Статистика

Экран канала и экран выложенного ролика: счётчики, график за период, время последней синхронизации. Если метрику канал не отдаёт, ячейка показывает «нет в этом канале».

Готово, когда цифры в программе сходятся с YouTube Studio на одном и том же ролике с учётом задержки аналитики.

### После этапа 11

Свободный агент поверх тех же инструментов: сам выбирает шаг, останавливается на ошибке, не обходит выключенные инструменты. В этапы 1–11 он не входит.

## 11. Правила для разработки

- Стиль брать из `docs/youtube-dark-style.md`.
- Этап N не тянет функции этапа N+1. На каркасе нет настоящих папок. На библиотеке нет таймлайна. На тексте и голосе нет выгрузки.
- Пока ролик не выбран, рабочая область пустая, инструменты выключены.
- Секреты моделей и Google остаются на машине пользователя, в защищённом хранилище.
- Генерация видео и голоса кладёт результат на таймлайн.
- Публикация идёт из экспорта этапа 6 на каналы, подключённые на этапе 9.
- Новый код — C++20.

## 12. Рабочие решения, которые можно поменять отдельным решением

Эти пункты уже приняты для разработки. Менять их нужно явным решением, а не по ходу этапа:

- UI — Qt 6 и Qt Quick;
- вложенная папка наследует промпт родителя и добавляет свой;
- предел длительности до сверки с YouTube на этапе 10 — 180 секунд;
- первый поставщик генерации видео выбирается в начале этапа 8;
- музыка на этапах 1–11 добавляется файлом;
- поиск ищет имена папок и роликов.
