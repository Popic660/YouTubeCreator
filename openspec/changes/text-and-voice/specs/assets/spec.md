# Spec Delta

## ADDED Requirements

### Requirement: Голос становится ассетом пула
Успешный шаг голоса SHALL скопировать аудиофайл в `media/` и SHALL создать аудиоассет в пуле. Новый шортс из этого файла SHALL NOT создаваться. Несколько роликов SHALL ссылаться на этот ассет без второй копии файла.

#### Scenario: Файл голоса в пуле
- **WHEN** шаг голоса завершился успешно
- **THEN** в пуле есть аудиоассет, копия лежит в `media/`, а число роликов не выросло

#### Scenario: Тот же файл на втором ролике
- **WHEN** пользователь кладёт уже сгенерированный голосовой ассет на другой ролик
- **THEN** на втором ролике появляется клип, а число файлов в `media/` не растёт
