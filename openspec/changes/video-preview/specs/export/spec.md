# Spec Delta

## Purpose

Сборка таймлайна выбранного ролика в вертикальный файл mp4 1080×1920, который совпадает с тем, что видно в кадре.

## ADDED Requirements

### Requirement: Файл экспорта
Пользователь SHALL экспортировать выбранный ролик с клипами в файл mp4 шириной 1080 и высотой 1920, с видео H.264 и звуком AAC.

#### Scenario: Вертикальный mp4
- **WHEN** пользователь экспортирует ролик с клипом на V1
- **THEN** появляется файл mp4 1080×1920 с дорожками H.264 и AAC

#### Scenario: Нет клипов
- **WHEN** выбран ролик без клипов и пользователь запускает экспорт
- **THEN** файл экспорта не создаётся

### Requirement: Совпадение с кадром
Экспортированный файл SHALL показывать те же склейки, кадрирование, масштаб, положение, текст и громкость, что видны в кадре на таймлайне этого ролика.

#### Scenario: Склейка и громкость
- **WHEN** на таймлайне два видеоклипа и уменьшенная громкость звука, и пользователь экспортирует ролик
- **THEN** в файле те же стыки клипов и та же относительная громкость, что в кадре

#### Scenario: Кадрирование
- **WHEN** горизонтальный исходник вписан в 9:16 и пользователь экспортирует ролик
- **THEN** в файле тот же вертикальный кадр, что на экране

### Requirement: Каталог экспорта
Файл экспорта SHALL сохраняться в каталоге `exports/` выбранной библиотеки.

#### Scenario: Путь файла
- **WHEN** экспорт завершился успешно
- **THEN** готовый mp4 лежит в `exports/` папки библиотеки
