# Spec Delta

## ADDED Requirements

### Requirement: Импорт видео в папку
Пользователь SHALL импортировать видеофайл в папку библиотеки. Программа SHALL скопировать файл в каталог `media/` этой библиотеки и SHALL создать или заполнить ролик клипом на V1. Исходник вне библиотеки SHALL NOT стать единственной копией материала.

#### Scenario: Новый ролик из файла
- **WHEN** пользователь импортирует видеофайл в папку
- **THEN** в этой папке появляется ролик с клипом, а копия файла лежит в `media/` библиотеки

#### Scenario: Черновик получает файл
- **WHEN** пользователь импортирует видеофайл в существующий ролик без клипов
- **THEN** у этого ролика появляется клип на V1, имя ролика не обязано совпасть с именем файла

#### Scenario: Отказ от выбора файла
- **WHEN** пользователь открывает импорт и не выбирает файл
- **THEN** новых роликов и копий в `media/` нет

### Requirement: Превью карточки с кадром
Когда у ролика есть кадр или постер, карточка в дереве SHALL показывать это превью. Радиус превью SHALL быть 12px. Заголовок SHALL быть не длиннее двух строк. Длительность SHALL быть бейджем на превью.

#### Scenario: После импорта
- **WHEN** у ролика есть кадр после импорта
- **THEN** карточка показывает превью радиусом 12px, заголовок не длиннее двух строк и бейдж длительности

### Requirement: Выбор ролика с материалом
Выбор ролика, у которого есть клипы, SHALL заполнять кадр 9:16 составом таймлайна и SHALL показывать клипы на таймлайне. Выбор ролика без клипов SHALL NOT заполнять кадр и SHALL NOT добавлять клипы на таймлайн.

#### Scenario: Ролик с файлом выбран
- **WHEN** пользователь выбирает ролик с импортированным клипом
- **THEN** кадр показывает состав таймлайна, на таймлайне есть клип

#### Scenario: Черновик выбран
- **WHEN** пользователь выбирает ролик без клипов
- **THEN** кадр остаётся пустой областью 9:16, на таймлайне нет клипов

## MODIFIED Requirements

### Requirement: Удаление ролика
Ролик SHALL удаляться только после подтверждения. До подтверждения запись SHALL оставаться в библиотеке. После подтверждения программа SHALL удалить запись ролика, его `shorts/<id>/` и неиспользуемые копии материала в `media/`.

#### Scenario: Отказ удалить ролик
- **WHEN** пользователь отказывается подтвердить удаление ролика
- **THEN** ролик остаётся в прежней папке

#### Scenario: Подтверждение удаления ролика
- **WHEN** пользователь подтверждает удаление ролика
- **THEN** ролик исчезает из библиотеки

#### Scenario: Файлы после подтверждения
- **WHEN** пользователь подтверждает удаление ролика с импортированным файлом, на который нет других ссылок
- **THEN** каталог ролика и эта копия в `media/` исчезают с диска

## REMOVED Requirements

### Requirement: Выбор ролика не открывает монтаж
**Reason**: Этап 3 открывает кадр и таймлайн у ролика с материалом. Пустой черновик по-прежнему не заполняет кадр — это покрывает новое требование «Выбор ролика с материалом».
**Migration**: Для ролика без клипов проверять пустой кадр. Для ролика с клипами проверять состав таймлайна в кадре.
