# Proposal

## Why

Каналы подключены, экспорт и 16:9 обложка лежат на диске, но выгрузить ролик некуда: в шапке нет «Опубликовать», id видео не пишется, экран аналитики не открывается. Этапы 10 и 11 ТЗ — публикация и статистика. Их делаем одним изменением: статистика без `video id` пустая, публикация без экрана оставляет «выложен» слепым.

## What Changes

- Одна залитая кнопка «Опубликовать» в шапке. «Экспорт» остаётся рядом как тональная. В диалоге уже стоят название (имя ролика) и описание (сценарий); пользователь отмечает каналы и выбирает приватность: личный, по ссылке или открытый.
- Перед отправкой проверяются файл экспорта, вертикальный кадр и длительность не длиннее 180 секунд (предел Shorts после сверки с YouTube). Остаток квоты выгрузок виден до нажатия «Опубликовать».
- Загрузка идёт на каждый выбранный канал отдельно: свой прогресс, свой статус, свой id видео. Сбой одного канала не отменяет остальные. 16:9 обложка уходит в API, если канал её принимает; иначе публикация без своей обложки и это видно в статусе.
- После хотя бы одной успешной выгрузки статус ролика — выложен. Пользователь статус вручную не выбирает.
- Статистика запрашивается явно. Экран канала — из меню шапки по названию канала. Экран выложенного ролика — отдельным действием, не вместо выбора ролика в дереве: таймлайн и кадр при обычном выборе остаются. На экране статистики таймлайн скрыт, дерево на месте.
- По ролику: просмотры, лайки, комментарии. По каналу: подписчики и суммарные просмотры. По Analytics API за период: просмотры, время просмотра, средняя длительность, лайки. Показы и CTR — число или «нет в этом канале». График по гайду, подпись про задержку до двух суток, время последней синхронизации локально.
- Цифры квоты в `docs/tz.md` приводятся к актуальной документации Google: отдельное ведро `videos.insert`, не старые 1 600 единиц из 10 000.

Не входит: свободный агент, смена поставщика OAuth, живой Google в `shell_tests`, создание аккаунта YouTube, повторный запрос scopes (они уже выданы на этапе 9).

## Capabilities

### New Capabilities

- `publish`: диалог публикации, проверки перед отправкой, загрузка на выбранные каналы, квота, обложка в API, прогресс и id видео по каналу.
- `analytics`: экран канала и выложенного ролика, явная синхронизация, локальный снимок счётчиков и графика за период.

### Modified Capabilities

- `library`: таблица публикаций и снимки статистики; статус выложен после успеха; токенов в sqlite по-прежнему нет.
- `main-window`: залитая «Опубликовать» в шапке; режим аналитики в центре; таймлайн на этом режиме скрыт.
- `channels`: название канала в меню открывает статистику; access-токен обновляется из refresh; снят запрет этапа 9 на загрузку и аналитику.

## Impact

- Миграция `library.db` на `user_version` 7: таблицы публикаций и снимков статистики. Access-токен по-прежнему только в памяти.
- Новые C++20-типы рядом с `CChannelAuth`: обновление access-токена, resumable `videos.insert`, `thumbnails.set`, чтение Data API и Analytics API. `CHttpTransport` получает PUT и заголовки загрузки. `CLibraryStore` пишет публикации, статусы выгрузки и кэш метрик.
- QML: кнопка «Опубликовать», диалог по гайду, экран аналитики (`plot` `#3f3f3f`, периоды чипами). Hint каналов больше не говорит, что публикация выключена.
- Тесты `tst_library.qml` / `tst_shell.qml` / `tst_pipeline.qml`: YouTube API подставляется очередью заглушки. Живых `videos.insert` и Analytics в `shell_tests` нет.
- ТЗ `docs/tz.md`: квота этапа 10 — 100 вызовов `videos.insert` в сутки (1 единица в своём ведре), общий пул 10 000 на остальные методы. Предел длительности 180 секунд не меняется.
