# Spec Delta

## ADDED Requirements

### Requirement: Видео сцены становится ассетом пула
Успешный шаг видео SHALL скопировать файл каждой сцены в `media/` и SHALL создать видеоассет в пуле. Новый шортс из этого файла SHALL NOT создаваться. Несколько роликов SHALL ссылаться на этот ассет без второй копии файла.

#### Scenario: Файл сцены в пуле
- **WHEN** шаг видео завершился успешно для сцены
- **THEN** в пуле есть видеоассет, копия лежит в `media/`, а число роликов не выросло

#### Scenario: Тот же клип на втором ролике
- **WHEN** пользователь кладёт уже сгенерированный видеоассет на другой ролик
- **THEN** на втором ролике появляется клип, а число файлов в `media/` не растёт
