# Spec Delta

## MODIFIED Requirements

### Requirement: Статус генерации
Пока выполняется задача конвейера, статус ролика SHALL быть генерация. После ошибки или отмены статус SHALL снова быть черновик. После успеха клипов сцен и постера карточки статус SHALL быть готов. Пользователь SHALL NOT выбирать статус вручную. Статус выложен этот этап SHALL NOT ставить.

#### Scenario: Во время задачи
- **WHEN** конвейер выполняется для ролика
- **THEN** статус этого ролика — генерация

#### Scenario: После успеха
- **WHEN** клипы сцен и постер карточки записаны успешно
- **THEN** статус ролика — готов, а не черновик и не выложен

#### Scenario: После ошибки видео
- **WHEN** шаг видео возвращает ошибку
- **THEN** статус ролика снова черновик, сценарий и голос на месте

## ADDED Requirements

### Requirement: Сцены сценария
Программа SHALL разобрать сценарий ролика на сцены. Если списка сцен нет, весь сценарий SHALL считаться одной сценой. Поиск SHALL NOT учитывать текст сцен отдельно от имён.

#### Scenario: Несколько сцен
- **WHEN** сценарий содержит список сцен и пользователь запускает шаг видео
- **THEN** шаг видео получает больше одной сцены

#### Scenario: Цельный сценарий
- **WHEN** сценарий — сплошной текст без списка сцен
- **THEN** шаг видео получает одну сцену с этим текстом

### Requirement: Постер карточки с первого кадра
Когда на видеодорожке появляется первый клип конвейера, карточка ролика SHALL показать вертикальный постер — кадр в нуле ролика. Отдельный вызов модели для постера карточки SHALL NOT выполняться.

#### Scenario: Превью после клипов
- **WHEN** шаг видео положил клипы на видеодорожку
- **THEN** карточка показывает превью радиусом 12px и бейдж длительности, а не заглушку

#### Scenario: Постер без image-API
- **WHEN** постер карточки записан после шага видео
- **THEN** запроса к image-API для этой карточки не было

### Requirement: Обложка YouTube в файле ролика
У ролика SHALL храниться горизонтальная 16:9 обложка для YouTube в файле проекта. После перезапуска файл SHALL остаться. Публикация на канал SHALL NOT входить в этот этап.

#### Scenario: Обложка после шага
- **WHEN** шаг обложки завершился успешно
- **THEN** у ролика есть файл 16:9 обложки

#### Scenario: Обложка после перезапуска
- **WHEN** обложка записана, пользователь закрыл программу и открыл ту же библиотеку
- **THEN** файл обложки этого ролика на месте
